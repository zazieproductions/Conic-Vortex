# Changelog

All notable changes to Y̷Y̶Y̸Y̵Y̷Y̶Y̸ are documented here. The format is
based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.3.0] — Unreleased

### Added

- **Procedurally generated public assets**: `public/sprites/{eye,goat,sun}.png`
  and `public/{favicon.svg,favicon.png}` are now generated by
  `scripts/generate-assets.mjs` (zero runtime dependencies) so the
  project builds and runs from a clean clone with no 404s.
- **Clear folder architecture**: `src/audio/`, `src/components/`,
  `src/data/`, `src/utils/` replace the flat `src/lib` + untyped
  structure. Content strings and palettes are separated from rendering
  logic in `src/data/`.
- **`src/audio/engine.ts`** replaces `src/lib/noise.ts` with documented
  exports (`initAudio`, `blip`, `scream`, `toggleMute`, `isMuted`,
  `isInitialized`) and JSDoc on the module and constants.
- **`WarningGate.tsx`** extracted into its own component with
  `role="alertdialog"`, `aria-modal`, and proper accessible naming.
- **ARIA labels** on every interactive control (warning gate accept,
  popup close/accept, escape button, control-altar buttons).
- **`src/utils/id.ts`** — collision-resistant ID generator using
  `crypto.randomUUID()` (replacing module-level `let popupId = 0;
popupId++` which produced duplicate IDs under React 19 StrictMode
  and after HMR).
- **Prettier** for code formatting, integrated via `format`,
  `format:check`, and `validate` scripts.
- **`npm run validate`** umbrella script: typecheck + lint + format:check + build.
- **Per-subsystem docs** under `docs/`:
  - `docs/architecture/overview.md`
  - `docs/architecture/three-chaos.md`
  - `docs/architecture/popup-hell.md`
  - `docs/audio/engine.md`
  - `docs/development/workflow.md`
- **Mermaid diagrams** in README and architecture docs illustrating
  layer composition and state flow.
- **Repository metadata**: `package.json` description, `homepage`,
  `engines.node`, proper project name (`conic-vortex`).
- **Vite `base: './'`** default for portable builds (overridable via
  `VITE_BASE`); `server.allowedHosts: true` for preview environments.
- **Build config** tweaks: explicit `target: 'es2022'`, source maps in
  non-production, chunk size warning limit raised.
- **`.prettierrc.json`** and `.prettierignore`.
- **Expanded `.gitignore`** covering env files, build/coverage dirs,
  platform deploy dirs, OS/editor detritus.

### Changed

- **Package name** `placeholder-model-2` → `conic-vortex`.
- **Cleaner `index.html`** — removed Arena-specific recording,
  analytics, and element-picker scripts that were injected by the
  development sandbox but do not belong in canonical source.
- **Vite config** simplified; optional `.vite-source-tags.js` is
  dynamically imported in a guarded `try/catch` so the project builds
  identically inside and outside Arena.
- **ThreeChaos cleanup** — materials are now properly disposed on
  unmount (with an Array-aware dispose helper to satisfy TS and avoid
  leaks).
- **ESLint config** — broader ignores (build dirs, public,
  `.vite-source-tags.js`), `@typescript-eslint/no-unused-vars` as warn
  with `_` prefix exemption, `no-explicit-any` warn.
- **`tsconfig.app.json`** enables `noUnusedLocals`, `noUnusedParameters`,
  and `noUncheckedSideEffectImports` (consistent with node tsconfig).
- **Scripts reorganised**: `capture:screenshots` → `screenshots`;
  `assets:generate` added; `typecheck`, `lint:fix`, `format`,
  `format:check`, `validate` added.

### Removed

- **Unused dependencies**: `framer-motion`, `lucide-react`,
  `react-router-dom` (declared but never imported; they were inflating
  install time and audit surface).
- **Duplicate lockfile** `pnpm-lock.yaml` (npm is canonical).
- **Duplicate screenshot script** `scripts/puppeteer-screenshot.mjs`
  (subsumed by `capture-screenshots.mjs`).
- **Empty `src/App.css`**.
- **Old `src/lib/noise.ts`** (replaced by `src/audio/engine.ts`).

### Fixed

- **Broken sprite references** (`/sprites/eye.png`, `goat.png`, `sun.png`)
  and missing favicon — the app now ships with generated assets instead
  of relying on files that didn't exist in the repository.
- **Hydra-rule popup key collisions** from the module-level ID counter
  (now uses UUIDs).
- **Potential WebGL material-dispose TypeError** when a mesh material is
  an array.
- **Vite preview host rejection** by setting `server.allowedHosts: true`.

## [0.2.0] — 2026-09-03

### Added

- Full architecture documentation (`ARCHITECTURE.md`) and creative methodology notes.
- Puppeteer screenshot capture script (`scripts/capture-screenshots.mjs`).
- GitHub Actions Pages deployment workflow.
- Warning gate with photosensitive epilepsy warning.
- Visitor counter, intensity control (1–5), mute toggle, invert toggle, fleeing escape button.
- Full audio engine: 4-voice beating drone with LFO modulation, blips, scream.
- Three.js scene: 44 meshes, 900 particles, 21 sprites.
- Marquee layer (8 strips), symbol storm, popup hell (hydra rule), cursor trail.
- Glitch, rainbow-text, VHS, strobe, checker, conic-spiral CSS animations.
- 6 custom Google Font families via TailwindCSS 4 `@theme`.
- TypeScript strict mode, ESLint React Hooks plugin.
- Vite 7 + React 19 + TailwindCSS 4 + Three.js 0.185 stack.

### Changed

- README rewritten to document architecture, signal flow, design system, performance, and accessibility.
- All CSS consolidated into `src/index.css`.
